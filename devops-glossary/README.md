# 📖 DevOps Glossary — Beginner, Intermediate & Advanced Terms

> **~360 DevOps terms** explained in plain English, in three levels. Every term has a
> definition, a real-world example, and (from intermediate up) a ⚠️ gotcha or interview tip.
> Vendor-neutral. For Azure-specific terms, see the [Azure Glossary](../azure-glossary/azure_glossary.md).

## 🧭 Which level should I read?

| If you… | Start with |
|---------|-----------|
| Are new to IT/DevOps, or switching careers | 🌱 [Beginner Terms](beginner-terms.md) |
| Know Git, Linux basics and have seen a pipeline or a container | 🧩 [Intermediate Terms](intermediate-terms.md) |
| Run production systems, prepare for senior/SRE/platform interviews | 🚀 [Advanced Terms](advanced-terms.md) |

Recommended learning order: **Beginner → Intermediate → Advanced**. Each level links back to the
earlier ones where a concept is introduced.
