## PART 2 — Project Case Studies

### Case Study 1: Wedding Photo Edit (200 Photos in 2 Days)

Process a complete wedding photo set from RAW to delivery:
- Cull 800 RAW files down to 200 selects
- Batch color correction for consistent look across venues (church, outdoor, reception)
- Individual retouching for 30 hero portraits
- Skin retouching (frequency separation for close-ups)
- Creative color grade (warm, romantic tone)
- Export: high-res for print + web gallery + social media

**Cover in the case study:**
- Workflow diagram (ASCII): Import → Cull → Base Edit → Batch Apply → Hero Edits → Retouch → Export
- Software: Lightroom Classic (batch) + Photoshop (retouching)
- Culling strategy: star ratings, flags, color labels
- Preset creation: base preset → adjust per lighting condition
- Skin retouching workflow: healing → frequency separation → dodge & burn
- White balance challenges: mixed lighting (tungsten + daylight)
- Export presets: Print (TIFF, 300DPI) + Web (JPEG, 2048px, sRGB) + Social (1080×1350)
- Client delivery: online gallery (Pixieset, SmugMug)
- Backup strategy
- Lessons learned & common mistakes

### Case Study 2: Product Photography Edit for E-Commerce (50 Products)

Edit product photos for an online store:
- White background isolation (clipping path)
- Consistent lighting/exposure across all products
- Color accuracy (product must match real life)
- Shadow creation (drop shadow / reflection)
- Lifestyle composite (product placed in scene)
- Export for Shopify/Amazon requirements

**Cover in the case study:**
- Workflow diagram (ASCII): Shoot → Batch RAW Edit → Background Removal → Retouch → Composite → Export
- Software: Lightroom (RAW processing) + Photoshop (compositing, paths)
- Background removal: Pen Tool vs AI Select Subject comparison
- Color accuracy: ColorChecker Passport, consistent white balance
- Shadow techniques: drop shadow, reflection shadow, natural shadow
- Batch processing: Photoshop Actions for repetitive tasks
- Platform requirements: Amazon (1000×1000, white bg, RGB), Shopify
- File naming convention for SKUs
- Lessons learned & efficiency tips
