# 🧪 Azure Labs — Hands-On Scenarios

> Six progressive batches of real-world Azure scenarios. Complete them **in order**, because each
> batch builds on the previous one.

| # | Batch | Scenarios | Topics |
|---|-------|-----------|--------|
| 1 | [Foundations & Core Infrastructure](batch-1-foundations-and-core-infrastructure.md) (🟢 Beginner) | 1–5 | Subscription & resource-group strategy, VMs, networking fundamentals, storage, App Service |
| 2 | [Security, Identity & Advanced Networking](batch-2-security-identity-and-networking.md) | 6–10 | Entra ID, Key Vault, Azure Firewall & network security, load balancing & traffic management, VPN Gateway & ExpressRoute |
| 3 | [Containers, Databases & Messaging](batch-3-containers-databases-and-messaging.md) | 11–16 | ACR & ACI, AKS fundamentals & advanced, Azure SQL & Cosmos DB, messaging & event-driven, Redis Cache & CDN |
| 4 | [Serverless, CI/CD & Infrastructure as Code](batch-4-serverless-cicd-and-iac.md) | 17–22 | Azure Functions, Logic Apps & integration, Azure DevOps CI/CD, GitHub Actions for Azure, Bicep, Terraform on Azure |
| 5 | [Monitoring, Governance & Cost Management](batch-5-monitoring-governance-and-cost.md) | 23–27 | Azure Monitor & App Insights, governance at scale, cost management, logging/auditing/compliance, Backup & Site Recovery |
| 6 | [Advanced Architecture Patterns & Real-World Projects](batch-6-advanced-architecture-patterns.md) | 28–34 | Multi-region active-active, microservices, event-driven & CQRS, zero trust, migration, landing zones, performance testing & chaos engineering |

**Before starting:** read the [Azure Services Handbook](../azure-services/azure_services_handbook.md),
and set a **budget alert** on your subscription.
